🚀 Piloto Automático

Configurá las estrategias de IA para vender más sin esfuerzo.

🏠 Radar de Vecinos

Cuando un pedido sale "En Ruta", avisa a los vecinos cercanos (200m) que no compran hace tiempo.

Cómo funciona esta estrategia
Se activa cuando un pedido pasa a En Ruta. El sistema busca clientes cercanos que cumplan los días sin compra y les envía este mensaje.
  • Radio: distancia máxima desde el punto de entrega.
  • Días sin compra: evita enviar a clientes muy recientes.
  • Podés usar {cliente} para personalizar el texto.
🧠 Mayordomo IA (Predictivo)

Analiza el consumo histórico y envía un mensaje proactivo el día exacto de reposición.

Cómo funciona esta estrategia
Estima la próxima fecha de recompra según historial del cliente y dispara un mensaje antes de que se quede sin stock.
  • Ideal para clientes frecuentes con patrón estable.
  • Usá mensajes cortos y con propuesta concreta.
  • Podés usar {cliente} para personalizar.
🎁 Dominación de Zona (Viral)

Cuando entregás un pedido, envía un link único. Si un vecino compra, premiamos al cliente.

Cómo funciona esta estrategia
Cada cliente recibe un link/referencia. Si trae una venta válida, se genera una recompensa automática.
  • Producto y cantidad: definen el premio.
  • Mensaje invitación: texto que recibe para compartir.
  • Mensaje éxito: confirmación cuando gana el premio.
🔁 Reactivación Inteligente

Detecta clientes sin compra reciente y dispara una campaña automática para recuperarlos.

Cómo funciona esta estrategia
Revisa clientes inactivos y los contacta de forma gradual para recuperar ventas.
  • Días sin compra: define cuándo entra en campaña.
  • Máx. intentos: limita insistencia por cliente.
  • Recomendación: empezar con mensajes amigables, no agresivos.
📦 Post-Entrega + Upsell

Después de entregar, hace seguimiento y propone compra complementaria.

Cómo funciona esta estrategia
Envía un mensaje automáticamente unas horas después de la entrega para confirmar satisfacción y abrir upsell.
  • Horas post-entrega: espera antes del contacto.
  • Producto sugerido: opcional para completar el mensaje.
  • Funciona mejor con tono consultivo: “¿te agrego…?”.
🌤️ Campaña por Clima

Activa mensajes especiales en días de calor/frío para anticipar demanda.

Cómo funciona esta estrategia
Evalúa la temperatura del día y dispara mensajes distintos según calor o frío/lluvia.
  • Umbral calor: desde qué temperatura usa campaña de calor.
  • Umbral frío: desde qué temperatura usa campaña de frío.
  • Definí mensajes cortos y con CTA claro.
👑 Programa VIP

Premia la frecuencia de compra para mejorar retención y recompra.

Cómo funciona esta estrategia
Al alcanzar cierta cantidad de pedidos, el cliente entra en nivel VIP y recibe un beneficio definido.
  • Pedidos mín.: condición para activar beneficio.
  • Beneficio: texto libre (ej. bidón bonificado).
  • Se recomienda mantener beneficio simple y medible.
